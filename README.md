# Customer Segmentation using Unsupervised Machine Learning

This repository contains a machine learning project on customer segmentation using the EastWest Airlines dataset. Various unsupervised learning techniques including K-Means, Hierarchical Clustering, and DBSCAN are implemented and compared to identify meaningful customer groups.
